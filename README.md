# OSB 텀블벅 펀딩 리워드 배포 (2026)

텀블벅 펀딩 상세페이지에서 안내하는 **무료 체험판**과 **리워드 파일**을 배포하는 저장소입니다.

## 무료 체험판 (펀딩 참여 전 확인용)

| 파일 | 내용 |
|---|---|
| `track1_demo_chapter1.xlsx` | 엑셀 방탈출 체험판 — 프롤로그 + 챕터 1 (출입 통제 로그) |
| `track2_demo_formula.xlsx` | 머니 OS 기능 체험판 — 할부 계산기 + 월 집계 |

체험판은 **본편과 다른 예시 데이터**를 사용합니다. 본편의 사건·인물·정답은 체험판에 들어 있지 않습니다.

## 구동 환경

- 데스크톱 Microsoft Excel 2016 이상 (Windows · macOS)
- 웹용·모바일용 Excel, Google 스프레드시트, 한셀, Apple Numbers는 지원하지 않습니다.
- 매크로(VBA)를 사용하지 않으므로 매크로 차단 경고가 뜨지 않습니다.

## 다운로드

우측 **Releases** 항목에서 파일을 내려받으실 수 있습니다.
